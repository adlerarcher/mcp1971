Gaps against the rule set

Each was found by comparing the rule set against real federal data, not by review. Implications live on the About page.

Wilderness Study Areas

Finding
Three Wilderness Study Areas sit adjacent to the project. The rule set has no WSA review.

Evidence
Clan Alpine Mountains Wilderness Study Area; Stillwater Range Wilderness Study Area; Job Peak Wilderness Study Area. Managing agency: BLM.

Source
USGS PAD-US Captured

Tribal consultation

Finding
Eight federal reservations fall within consultation range. The rule set models NHPA Section 106 with SHPO only and has no tribal consultation row.

Evidence
Eight Census TIGERweb federal reservations in Nevada.

Source
Census TIGERweb Captured

Geothermal EA activity types

Finding
Real geothermal EAs cover pipelines, electricity transmission, surface transportation, waste management, and vegetation and fuels management. The rule set has no corresponding reviews.

Evidence
Pipelines; Electricity Transmission; Surface Transportation - Other; Waste Management; Vegetation and Fuels Management.

Source
PNNL NEPATEC 2.0 Extracted

Nevada well permits

Finding
Nevada requires permits the rule set does not model: a Geothermal Project Area Permit, a Sundry Notice, and a well completion report due within 60 days. The rule set has one APD row.

Evidence
OpenEI RAPID Nevada Drilling & Well Development narrative.

Source
OpenEI RAPID Captured

Prototype. Lease and well records simulated. Not an official DOE product. Timeline.
